# Node API Boilerplate CLI

A simple interactive CLI tool to quickly scaffold production-ready Node.js backend boilerplates.

This tool allows you to select a framework, clone a structured boilerplate project, install dependencies, and generate a `.env` configuration automatically.

---

## Features

- Interactive framework selection
- Automatic repository cloning
- Removes existing git history
- Project folder renaming
- Automatic dependency installation using Yarn
- Guided `.env` file creation
- Clean production-ready project setup

---

## Supported Frameworks

Currently supported templates:

- Express Boilerplate
- Hapi.js TypeScript Boilerplate
- NestJS Boilerplate

---

## Installation

Install globally using npm:

```bash
npm install -g api-boilerplate-cli
